# Boarding House Management System

A web-based boarding house management system built with PHP and MySQL. This project is currently a work in progress.

## Features (In Development)
- Visual floor plan dashboard
- Tenant management
- Payment tracking
- Occupancy reports

## Built With
- PHP
- MySQL
- HTML & CSS
- JavaScript

## Status
This project is still under development. Some features may be incomplete or subject to change.
